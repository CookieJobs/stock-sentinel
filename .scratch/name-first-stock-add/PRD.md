# PRD: 名称优先的股票监控新增流程

Status: done
Owner: agent
Version: 1.0
Date: 2026-08-28

## Problem Statement

当前新增弹窗要求用户同时填写股票代码和名称，并暴露了提醒设置。对只记得公司名的用户，这不是必要负担；而同一公司跨市场挂牌时，直接自动加入会造成误监控或漏监控。

## Solution

1. 弹窗只保留「搜索股票名称」输入框，复用既有 `/api/quant/search` 名称/拼音搜索能力。
2. 用户点击普通候选后，直接以默认设置加入监控；代码、市场和显示名称由候选项自动带入。
3. 当同名候选覆盖多个市场时，展示明确的范围确认：用户可勾选其中一个、多个，或一键全选后加入。
4. 提醒默认关闭，阈值等高级设置继续在加入后的编辑入口配置，不打断新增主路径。

## Interaction Rules

- 输入至少 1 个字符后延迟搜索；加载、无结果与搜索失败均在输入框下方说明。
- 普通候选展示「名称、代码、市场」，点击即加入。
- 多市场确认不自动全选；按钮明确显示「添加已选（N）」和「全选市场」。
- 批量加入会汇总成功与失败，已存在项保持服务端 409 语义并向用户说明。

## Conflict Boundary

新增交互封装在独立 `AddStockModal` 组件。`Dashboard.jsx` 仅替换原有弹窗入口与回调，不修改监控表格、筛选、统计或首页布局，以降低与首页优化会话的重叠。
