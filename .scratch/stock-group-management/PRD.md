# PRD: 股票监控批量操作与自定义分组

Status: done
Owner: agent
Version: 1.0
Date: 2026-08-28

## Problem Statement

监控列表只能逐只管理股票，且没有用户自定义的投资主题视图。用户难以快速清理多只已不再关注的股票，也无法同时按“长期持有”“科技”等多个主题组织同一标的。

## Solution

1. 新增持久化分组与多对多成员关系；同一股票可加入任意多个分组，分组数量不设产品上限。
2. 分离“删除自选”与“移出分组”：前者从全局监控删除并级联清理归属，后者仅移出当前分组；删除分组本身保留股票。
3. 监控表格提供当前可见行全选、批量加入分组、在分组视图中批量移出，以及带二次确认的批量删除。
4. 提供独立分组管理弹窗，可新建、重命名和删除分组；无分组时也可在批量加入流程内直接创建。

## Conflict Boundary

后端分组服务、API 与两个弹窗组件独立新增。Dashboard 只接入分组筛选、选择列和批量操作栏；基线使用已合并的首页监控优化提交 `a8412ae`，不触碰主工作区中未完成的回测合并冲突。
