# PRD: 股票监控新增股票可用性修复

Status: done
Owner: agent
Version: 1.0
Date: 2026-08-27

## Problem Statement

监控页已有「＋添加」弹窗，但它提示用户输入 `600519.SS/.SZ` 和 `0700.HK`；后端没有将这些格式转换成监控数据源使用的规范代码，A 股会被误判为美股，港股也可能无法得到行情。同时前端提交的可选名称不在 API 模型中，因而被丢弃。

## Solution

只调整后端新增股票流程，不修改首页 `Dashboard.jsx`：

1. 接受并规范化常用输入：A 股 `600519.SS/.SH/.SZ` 归为 `600519`，港股 `0700.HK` 或 `700.HK` 归为五位代码 `00700`。
2. `AddStockRequest` 接受可选 `name`；有手填名称时将其作为显示名，无名称时保持原有「行情名称→代码」降级。
3. 在规范化后判重，防止同一股票因后缀写法重复加入。
4. 为新增接口加临时 SQLite 集成测试，隔离真实 `data/sentinel.db` 和外部行情请求。

## Out of Scope

- 不改动首页股票监控模块的布局、弹窗交互或样式，避免与「优化首页股票监控模块」会话冲突。
- 不接入新数据源，也不改变刷新或告警语义。
