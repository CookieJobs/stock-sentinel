# PRD: 回测新手引导与名称选股

Status: done
Owner: agent
Version: 1.0
Date: 2026-08-27

## Problem Statement

`/backtest` 直接暴露 `ma_cross`、`fast`、`slow`、调仓频率、滑点等量化术语，用户需要先理解实现细节才能完成第一次回测。回测标的只接受手输代码，无法沿用 `/chart` 已有的中文名、拼音、代码联想搜索能力。

## Goal

让新手先表达“回测一只股票”或“比较一组股票”的意图，用名称或代码选择标的后即可运行；同时通过高级设置保留已有策略、参数、交易成本和基准配置。

## Solution

1. 把表单改为意图优先的三步流程：选择方式、选择标的、选择时间并运行。
2. 提供两种默认方式：
   - `跟随趋势`：单只股票，映射现有 `ma_cross` 策略及 MA5/MA20 默认参数。
   - `等权持有`：两只或以上股票，映射现有 `equal_weight` 策略，按月调仓。
3. 使用已有 `GET /api/quant/search` 搜索接口：支持名称、拼音和代码；选中结果显示名称、代码、市场标签，可删除，直接输入代码回车仍可添加。
4. 同一次回测限制为同一市场，避免现有后端单一 `market` 参数产生误导。提示用户另开回测比较不同市场。
5. 将策略引擎、策略参数、回测名称、初始资金、基准、调仓、手续费和滑点收进“高级设置”。
6. 在提交前显示一条人话摘要，说明将用何种方式、哪些标的、哪个区间和基准运行。
7. 保留策略模板和历史结果入口，但降低其在首次任务流中的视觉优先级。

## Out of Scope

- 改造 `/chart`、`/screener` 或后端搜索 API。
- 支持跨市场混合回测。
- 新增策略、数据源或改变回测引擎计算语义。

## Acceptance Criteria

- 输入“茅台”或“MAOTAI”可在回测页看到候选并选中“贵州茅台 600519”。
- 输入有效代码后按 Enter 可添加标的，即使搜索服务没有返回候选。
- 单股模式没有选中一只标的时不能提交；组合模式不足两只标的时给出明确提示。
- 同时加入不同市场标的时给出明确提示且不提交。
- 提交 payload 只传股票代码数组和所选市场，保持后端 API 兼容。
- 高级用户仍可调整原有策略、参数、资金、基准、调仓频率、手续费和滑点。
