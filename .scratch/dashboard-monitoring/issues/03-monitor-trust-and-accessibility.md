# Issue 03: 监控页的可信状态与可访问操作

Status: done

## What to build

让用户能在首页快速分辨真实风险、行情时效和页面状态。主表优先展示监控决策信息，次要指标按需查看；风险颜色只表示该股票的一年提醒状态或数据异常。加载失败、空自选股、筛选无结果和陈旧行情分别给出下一步操作。

排序、风险筛选和行内操作提供明确标签与键盘支持，避免依赖图标悬停和颜色判断。

## Acceptance criteria

- [x] 风险状态使用每只股票的启用开关、实际阈值和一年基线，不再使用隐藏的固定 -10%/-20% 色阶。
- [x] 页面显示实际行情更新时间；无历史覆盖时明确显示数据不足。
- [x] 表格在窄屏下仍优先显示股票、现价、区间高点、回撤和风险，空/错/筛选无结果状态可理解且可恢复。
- [x] 排序与周期切换使用语义化按钮、全局焦点样式和文字化风险状态；风险不只用颜色表达。
- [x] 前端 lint/build 与针对状态映射的测试通过。

## Comments
