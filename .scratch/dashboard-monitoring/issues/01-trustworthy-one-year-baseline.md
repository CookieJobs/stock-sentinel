# Issue 01: 可信的一年回撤基线

Status: done

## What to build

建立跨市场一致的滚动一年回撤数据并在首页完整解释。用户打开监控页时，默认视图应显示「距一年高点」、一年统计起点、截至时间、区间高点及高点日期，不再只留下无上下文的「回撤」。

风险提醒继续使用这一年基线，现有字段和历史记录保持兼容。A 股、港股和美股不得再因不同样本长度而对外宣称同一 52 周定义。

## Acceptance criteria

- [x] 每只股票返回可解释的一年窗口状态、起点、截至时间、高低点、日期、回撤和距低点；数据不足或不可用时不产生误导数值。
- [x] 既有 52 周 API 字段与一年窗口一致，现有提醒、简报和历史记录不被破坏。
- [x] 首页默认视图清楚说明一年窗口、统计区间和实际行情更新时间，概览与表格口径一致。
- [x] 一年窗口计算、迁移兼容、API 响应和提醒基准均有不依赖网络的回归测试。
