# Issue 02: 可切换的监控回撤窗口

Status: done

## What to build

在已可信的一年基线之上，让首页用户使用全局 3 个月、6 个月和 1 年切换器比较自选股。所选窗口同时驱动表格数值、排序、概览、30 天趋势和 CSV 导出，刷新数据时预计算，切换本身不发起逐只网络请求。

历史不足时该窗口显示明确的数据不足状态与可用起点。风险提醒仍固定于一年基线，页面窗口只改变研究视图。

## Acceptance criteria

- [x] 3m、6m、1y 的窗口数据、窗口化趋势查询与历史快照均可用，旧记录不被伪装成新窗口数据。
- [x] 首页默认一年并在本地记住选择；所有当前窗口相关的标题、概览、排序、趋势和导出同步更新。
- [x] 风险提醒配置、越线状态和历史告警始终标明一年基准，不随选择器改变。
- [x] 前端纯逻辑及后端窗口数据均有针对边界、数据不足和语义兼容的测试。

## Comments

- 2026-08-28：3m/6m/1y 选择会同时改变概览、排序、表格、30 天趋势和 CSV；窗口切换只请求本地历史 API，不会触发行情源。
