# PRD: 首页股票监控的可解释多周期回撤

Status: done
Owner: agent
Version: 1.0
Date: 2026-08-28

## Problem Statement

首页「回撤」列没有说明它相对哪一个高点、从何时开始统计、数据是否完整或何时更新。虽然界面相邻显示了 52W 高点和日期，用户仍需自行推断。更严重的是，美股与 A/港股目前使用不同长度的历史样本，却都标为 52W，跨市场比较和风险阈值解释不可信。

首页还把页面拉取时刻当成行情更新时间，使用固定 -10%/-20% 色阶表示风险，并在同一张宽表中混合监控决策信息和次要基本面字段。加载失败、没有股票、筛选无结果和数据过期也没有清晰区分。

## Solution

将「回撤」升级为全局可切换的 3 个月、6 个月和 1 年滚动窗口指标，并在同一位置展示统计区间、区间高点日期和行情截至时间。每一行和概览卡片始终基于当前选择的相同窗口比较。

风险提醒维持独立、稳定的 1 年基准，周期切换不改变已保存的提醒阈值或告警状态机。历史不足或数据不可用时不计算数值，只显示真实的数据状态。首页只保留监控所需的首层信息，提供明确的数据状态、风险状态、错误和空状态。

## User Stories

1. 作为个人投资者，我想在 3 个月、6 个月和 1 年间切换回撤窗口，以便按短中长期节奏比较自选股。
2. 作为首次使用者，我想直接知道「距一年高点」的起止日期、区间最高价和高点日期，以便不必猜测回撤含义。
3. 作为跨市场用户，我想让 A 股、港股和美股使用相同的日历窗口定义，以便比较结果可信。
4. 作为新股或历史数据不足的用户，我想看到数据不足与已覆盖日期，而不是被误导为完整周期的回撤。
5. 作为风险提醒用户，我想让已配置的关注线继续始终基于 1 年高点，以便网页浏览偏好不会意外改变提醒行为。
6. 作为监控用户，我想从表格直接分辨未启用、正常、已越线与行情过期，以便优先处理真正需要关注的股票。
7. 作为用户，我想让概览中的平均回撤和最深回撤随当前窗口同步变化，以便概览与表格结论一致。
8. 作为趋势查看者，我想让 30 天趋势线与当前选择的窗口相符，以便不会把一年回撤趋势误读为三个月回撤趋势。
9. 作为数据导出用户，我想让 CSV 标题清楚标明已选窗口与区间高低点，以便离线分析时保留指标语义。
10. 作为网络不稳定时的用户，我想区分初始加载失败、空自选股、筛选无结果和陈旧行情，以便知道下一步该重试、添加还是调整筛选。
11. 作为键盘和辅助技术用户，我想操作排序、风险筛选和行内设置，而不只依赖图标提示或颜色。

## Implementation Decisions

- 使用滚动日历窗口 `3m`、`6m`、`1y`，前端默认 `1y` 并在浏览器本地记住选择；同一选择影响表格、排序、概览、趋势和导出。
- 每次行情刷新从既有多源日线能力标准化计算窗口指标；每日 K 线缓存按股票、市场和交易日复用，切换窗口不发起逐只网络请求。
- 增加 `drawdown_windows`：窗口状态、统计起点、截至时刻、区间高低点及日期、回撤与距低点。状态为 `ok`、`insufficient_history` 或 `unavailable`；非 `ok` 的窗口不返回可比较数值。
- 既有 52 周字段继续保留以兼容现有 API、简报与历史告警，并统一对应新对象的 `1y` 定义。数据库迁移仅新增字段，不删除或改写股票、提醒和历史数据。
- 风险提醒只消费状态正常的 `1y` 指标。提醒的阈值、一次越线和恢复后重新布防规则保持不变。
- 首页把回撤列命名为「距 {窗口} 高点」，标题区域展示计算公式、统计区间和实际行情时刻。硬编码风险色阶从监控界面移除，风险颜色仅表示股票自己的提醒状态或数据异常。
- 主表合并股票市场、现价与当日涨跌、区间高点与日期；基本面及距低点作为按需展开的次要信息。风险概览可直接筛选已越线股票。
- 已合并的股票代码别名标准化与手动名称支持不在本需求中重复实现。

## Testing Decisions

- 新的窗口计算测试使用手工核对的日线 fixture，验证不同窗口边界、实时价格新高、短历史、不可用数据和跨市场统一口径。
- 监控 API 与 SQLite 测试验证新增字段、迁移兼容、窗口趋势查询，以及周期切换不会影响 1 年提醒。
- 前端将周期选择、统计/排序/导出映射提取为可单测的纯逻辑，使用 Node 原生测试；页面行为由 lint、build 和桌面/窄屏人工验收覆盖。
- 复用现有临时 SQLite 隔离测试模式；外部行情请求只在数据抓取冒烟测试中出现，单测不依赖网络。

## Out of Scope

- 成本价盈亏、持有期收益、止损、追踪止损和组合最大回撤。
- 每只股票单独选择提醒周期或让提醒跟随页面窗口。
- 新的数据供应商、付费服务或凭据配置。
- 重做其他量化页面的指标语义。
